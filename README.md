# Smart Resume Screener

Smart Resume Screener is a web application designed to make the resume screening process faster and easier. It allows users to upload multiple resumes and compare them with a given job description to help identify the most relevant candidates.

## 🚀 Live Demo

**Try the application:**
https://smart-resume-screener-2ywz-iota.vercel.app/

## 📌 Features

* Upload multiple resumes
* Supports resume screening against a job description
* Extracts and processes resume information
* Analyzes resumes based on the given job description
* Provides screening and ranking results
* Simple and user-friendly interface
* Deployed frontend and backend

## ⚙️ How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/mastani26/Smart-Resume-Screener.git
cd Smart-Resume-Screener
```

### 2. Start the backend

```bash
cd server
npm install
node server.js
```

### 3. Start the frontend

Open another terminal:

```bash
cd client
npm install
npm run dev
```

The frontend will then be available on the local Vite development URL shown in the terminal.
